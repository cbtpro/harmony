# Harmony

Harmony 是一个基于 Electron、Node.js、Vite 和 Vue 3 的桌面文件管理工具。

- 默认打开主目录，可通过系统目录选择器或绝对路径访问其他磁盘和文件夹。
- 文件夹排在列表前面，可以按名称筛选当前目录。
- 支持新建文件夹、使用系统默认应用打开文件、复制普通文件，以及将项目移到系统废纸篓。
- 复制遇到同名文件时保留已有文件。废纸篓操作需要确认，系统拒绝时在界面显示错误。

## 整理与预览

- 「全局搜索」支持按扩展名、目录、最近修改时间和最小大小筛选。多选普通文件后，可预览批量复制或移动，并对同名文件选择跳过、保留两份或替换。执行结果按文件列出。
- 在文件列表或搜索结果里选中文件行后按空格，可预览图片、PDF、文本和 Markdown。用方向键切换文件，PDF 内有独立的翻页按钮。图片和 PDF 的预览上限为 20 MiB，文本最多显示开头的 256 KiB。
- 「收藏目录」和「保存搜索」把当前位置或查询条件添加到侧栏，并保存在本机。桌面与网页共用这些收藏。可用逗号分隔多个扩展名，例如 `mp4,mkv,mov`，再搭配外接盘路径与最小文件大小。
- 「双栏」让两边独立浏览目录和维护标签，可将选中的文件和文件夹复制或移动到另一栏。目录预览列出目标、文件数量和跳过项，每批可预览最多 50,000 个目录项目。同名文件夹可跳过或保留两份。复制时跳过符号链接、目录联接和嵌套卷，移动包含这类项目的目录会在预览时提示。跨盘移动先在目标盘完成复制和校验，再清理源目录。
- Windows 文件操作支持超过 260 字符的绝对路径，包括 UNC 网络共享。名称仍受目标文件系统限制。移到废纸篓失败时保留原件。永久删除需要从右键菜单单独选择并确认。
- 文件页和搜索页的「批量重命名」支持查找替换、追加编号与当天日期。预览会列出冲突，确认时再次检查源文件和目标。

## 全局搜索

Harmony 默认优先查询系统索引。macOS 使用 Spotlight，Windows 使用 Windows Search，Linux 按可用情况尝试 GNOME LocalSearch、Tracker 或 KDE Baloo。未探测到可用系统索引的白名单目录会交给 Harmony 扫描。「全局搜索」显示各目录的索引来源。系统索引目录的结果取决于该系统实际收录的范围，仍会应用 Harmony 的黑名单。在「设置 → 文件索引」关闭「优先使用系统索引」可改用 Harmony 完整扫描。系统索引媒体查询每个目录最多取 10,000 个候选项。

macOS 桌面版可以从设置直接打开 Spotlight 设置，或请求重建启动数据卷的 Spotlight 索引。重建由 macOS 执行并要求管理员授权，其他磁盘或目录可在 Spotlight 的搜索隐私中操作。网页端可查询索引和调整 Harmony 的设置。

顶部搜索在输入时展示文件夹、程序、图片和文件的分组预览。方向键 ↑ / ↓ 可选择结果，按回车打开所选项。未选择结果时，按回车进入完整搜索页。预览结果也可使用右键菜单。

首次启动默认将用户主目录加入白名单，应用打开后自动开始扫描。可在「全局搜索」管理目录白名单和黑名单。黑名单排除目录及其所有子目录，包括同时出现在白名单里的目录。同一卷内的重叠白名单只扫描一次，移除父目录规则后仍可单独索引已选的子目录。规则保存到本机，修改后按新范围重建，清空白名单可关闭自动索引。

搜索按文件或文件夹名称匹配，忽略大小写，扫描期间也能查询已收录的项目。索引将名称、路径、类型和未完成的目录分批写入本机应用数据中的 SQLite 数据库。

访达、资源管理器等外部程序新增、删除、移动或重命名项目后，Harmony 会合并系统文件事件，只更新受影响的目录和新增的子树。只修改文件内容时，名称索引无需更新。macOS 和 Windows 使用系统递归监听，Linux 最多同时监听 256 个目录。对监听范围之外、事件丢失或不支持监听的文件系统，每轮扫描结束约 30 分钟后会自动补扫，也可立即重建。

在「设置 → 文件索引」可以配置扫描线程数。多线程系统至少留出一个系统线程，单线程系统使用一个扫描线程。新设置在下一轮扫描或从断点继续时生效。每个后台线程一次读取一个目录，文件浏览、复制等前台操作优先。

扫描可以暂停、继续或停止。退出时会保留已保存的进度，启动后自动继续被退出打断的任务，手动暂停或停止的任务可在「全局搜索」继续。续扫会跳过已经完成的目录，未完成的目录可能重新读取。应用关闭期间发生的文件变更由后续定时扫描补齐。最多添加 8 个白名单目录和 16 个黑名单目录，每次查询最多返回 100 项。

扫描会跳过点号开头的项目、`node_modules`、符号链接及部分系统目录。遇到无法读取的目录会跳过并在索引状态中显示数量。

启动后的首次索引、索引范围变更和手动重建结束后，客户端会发送静音系统通知。定时后台刷新保持静默。

## 磁盘与网页客户端

「磁盘」页面显示已挂载的卷、可用容量和索引范围。可以直接浏览，或将整个卷加入白名单。同一卷的整盘与子目录规则可以同时保留。未选择的挂载卷不会从其他卷的索引入口被递归扫描，黑名单在所有卷上都优先。可在「全局搜索」移除整盘规则或只保留需要的目录。

启动桌面客户端后，点击顶部「在浏览器打开」即可使用网页界面。网页与桌面窗口使用同一索引和文件引擎，访问的是客户端所在电脑。网页端选择目录时填写绝对路径，打开文件和移到废纸篓仍由本机系统处理。网页服务只监听本机回环地址，从客户端打开时自动建立当前标签页的会话，退出客户端即停止服务。

## 媒体库

「媒体库」使用全局索引的白名单与黑名单。支持电影、剧集、动画、其他视频、音乐、播客、其他音频、有声书、图片、电子书、漫画、字幕和播放列表。初始分类根据常见扩展名、目录名及剧集编号推断，可在媒体资料中调整。可以按分类筛选，也可查询文件名、资料标题、作者、流派或年份。

「资料与刮削」可编辑并保存本地资料，也可以读取文件大小和修改时间。系统安装 ffprobe 后，受支持的音视频和图片可以读取时长、分辨率、编码及内嵌标签。在线刮削使用 Wikidata 搜索电影，使用 iTunes 搜索剧集、音乐、播客和有声书，使用 Open Library 搜索图书。在线请求在点击查询后发送关键词，选中候选并保存后才会更新本地资料。资料保存在应用数据中。

重命名保留原扩展名和资料关联，同名文件会阻止操作。防覆盖重命名需要目标文件所在磁盘支持硬链接。

## 开发与测试

使用 Node.js 22.18 或更新版本。

```sh
npm ci
npm run dev
npm test
npm run build:app
npm run test:ui
```

UI 测试通过 Playwright 启动真实的 Electron 窗口，并在临时目录中操作文件。无图形桌面的 Linux 环境可用 `xvfb-run -a npm run test:ui`。

## 分层

- **界面层**在 `src/pages`，通过 `src/services/client.ts` 请求业务操作。桌面和网页共用页面及状态逻辑。
- **连接层**分别由 `electron/main/ipc.ts` 和 `electron/main/web-server.ts` 提供。桌面端验证请求来自主窗口，网页端验证本地地址、来源与会话凭证。
- **引擎层**由 `electron/main/engine.ts` 组织文件操作、磁盘发现及索引。引擎不依赖 Electron，通过注入的平台接口使用系统对话框、打开文件和废纸篓。
- **系统接入**在 `electron/main/index.ts`，负责窗口、系统动作、共享引擎及网页服务的生命周期。

## 打包

在目标操作系统上运行 `npm run build`，产物位于 `release/`。推送到 `main` 或手动运行 `Build and Release` 后，可以在 Actions 的运行记录里下载安装包。

### 发布版本

将 `package.json` 和 `package-lock.json` 的版本更新后提交到 `main`。推送与 `package.json` 版本一致的 `v` 标签，例如版本为 `1.0.0` 时使用 `v1.0.0`。

```sh
git tag -a v1.0.0 -m 'Harmony v1.0.0'
git push origin v1.0.0
```

跨平台测试与打包全部通过后，工作流会自动创建 GitHub Release，附上变更说明和 `SHA256SUMS`。带预发布后缀的版本会标记为预发布版本。

| 平台 | 架构 | 安装包 |
| --- | --- | --- |
| macOS | Apple Silicon（arm64）、Intel（x64） | DMG |
| Linux | x64 | AppImage、DEB |
| Windows | x64 | NSIS 安装程序（EXE） |

当前流程未配置正式签名证书，macOS 安装包未公证。
